# 루디트레이너

악보를 보고 L/R 패드를 쳐서 박자와 손 순서를 판정받는 드럼 루디먼트·초견 연습 웹앱.

- 루디먼트: 싱글/더블 스트로크, 패러디들, 플램 등 12종
- 초견: 레벨별 패턴 자동 생성
- 노래: 오디오 파일 BPM 자동 감지 후 그 위에 패턴 연습 (파일은 기기 밖으로 나가지 않음)
- 악보: 드럼 세트 악보 파일(.json)을 열어 한 줄로 흐르는 악보에 R/L을 붙여 연습

`index.html` 하나로 동작합니다. 폰 브라우저로 열어 사용하세요.

## 드럼 악보 파일 형식 (.json)

```json
{
  "title": "곡 제목",
  "bpm": 90,
  "grid": 16,
  "bars": [
    { "label": "벌스", "hh": "x-x-x-x-x-x-x-x-", "sd": "----o-------o---", "bd": "o-------o-o-----" },
    { "repeat": 3 },
    { "label": "필인", "sd": "oooo oooo ---- ----", "t1": "---- ---- oo-- ----", "ft": "---- ---- --oo oooo" }
  ]
}
```

- `grid`: 한 마디를 몇 칸으로 나누는지. 16(16분), 8(8분), 12(셋잇단), 4(4분), 24(6연음), 48(16분과 셋잇단이 섞인 마디). 마디마다 따로 줄 수도 있어요.
- `bpm`: 마디에 적으면 그 마디부터 템포가 바뀌어요. 앱의 템포 조절은 첫 템포 기준 비율로 전체에 적용돼요.
- 악기 줄: `cr` 크래시, `hh` 하이햇, `rd` 라이드, `t1` 하이탐, `t2` 미드탐, `sd` 스네어, `ft` 플로어탐, `bd` 베이스 드럼
- 칸 문자: `-` 또는 `.` 쉼표, 소문자(`x`, `o`) 침, 대문자 악센트, `g` 고스트 노트, 하이햇의 `o` 오픈 하이햇. 공백과 `|`는 무시돼요(보기 좋게 끊어 쓰기용).
- `{ "repeat": n }`: 바로 앞 마디를 n번 반복, `{ "repeat": n, "bars": m }`: 앞의 m마디 묶음을 n번 반복
- `stick`: 손을 직접 정하고 싶을 때 `R`, `L`, `B`(두 손)로 칸마다 지정. 비워 두면 자동.

**손 자동 결정 규칙:** 심벌(하이햇·크래시·라이드)은 R, 혼자 나온 스네어·탐은 L, 심벌과 북이 같이 나오면 두 손 동시, 북만 연달아 나오는 필인은 박자 위치로 R/L(16·8분은 정박 R·엇박 L, 셋잇단은 번갈아). 베이스 드럼은 악보에만 표시하고 판정하지 않아요.

저작권이 있는 곡의 악보 파일은 이 저장소에 올리지 말고 `songs/` 폴더(깃에서 제외됨)에 두세요.
